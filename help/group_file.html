「ファイル」グループ

音声ファイルの読み込みと、編集した音声の書き出しを行うコマンド群です。アプリ起動時はこのグループが開いています。

開く

Android 標準のファイル選択画面を開き、音声ファイルを 1 つ読み込みます。

  • 対応形式：wav・mp3・mp4（音声トラックのみ読み込みます。m4a も mp4 として開けます）。
  • 内部変換：入力のビット深度に関わらず 16 ビット符号付き PCM に変換して読み込みます（サンプリングレートとチャンネル数は元のまま保持します）。
  • 3 チャンネル以上のファイル：「読み込むチャンネル（2 つまで）」ダイアログが表示され、1 つ選ぶとモノラル、2 つ選ぶとステレオ（番号の小さい方を L、大きい方を R）として読み込みます。
  • 長さの上限：10,000 秒未満かつ 1,000,000,000 サンプル未満です。上限を超える場合は末尾が切り捨てられ、警告ダイアログが表示されます。
  • 未保存データがある場合：ファイル選択画面の前に確認ダイアログが表示され、保存して開く・保存しないで開く・キャンセル を選べます。
  • 読み込み中のキャンセル：読み込み中は「読み込んでいます…」ダイアログが表示され、キャンセル を押すと元の状態に戻ります。
履歴とコピーバッファ：新しいファイルを読み込むとアンドゥ履歴は空になりますが、コピーバッファの内容は維持されるため別ファイルへ貼り付けられます。

保存

音声データ全体をファイルに書き出します。

  • すでに 名前を付けて保存 を実行している場合は、前回と同じ保存先・形式・パラメータでダイアログを出さずに上書き保存します。
  • まだ 名前を付けて保存 を実行していない場合（または別ファイルを開き直した後）は、名前を付けて保存 と同じ動作になります。

名前を付けて保存

出力形式とパラメータを指定するダイアログを開き、OK を押したあとで保存先とファイル名を選んで音声データ全体を書き出します。

  • 保存に成功すると、保存先とパラメータが記憶され、次回の 保存 で再利用されます。
  • データファイル名の表示は保存したファイル名になり、未保存の印（* ）が外れます。

選択範囲を保存

開始位置から終了位置までの選択範囲だけを、指定した形式・パラメータでファイルに書き出します。

  • ファイルへ書き出すだけで、編集中の音声データ・未保存の状態・データファイル名の表示は変わりません。
  • 保存先は記憶しません（パラメータの初期値には直近の「名前を付けて保存」の設定が使われます）。

書き出し形式とパラメータ

書き出し時はサンプリングレートとチャンネル数を変換せず、現在の内部データのまま出力します。変換したい場合は事前に「全体の加工」で変換してください。

形式 設定項目 選択できる条件・備考
wav 量子化ビット数（16 ビット / 8 ビット、初期値 16 ビット） 常に選択可能。8 ビットは 16 ビットの上位 8 ビットを使用（ディザなし）。
mp3 ビットレート（64〜320 kbps、初期値 128 kbps） サンプリングレートが 8000 / 11025 / 12000 / 16000 / 22050 / 24000 / 32000 / 44100 / 48000 Hz のときのみ選択可能（LAME 3.100 使用・CBR）。低いサンプリングレートでは選べるビットレート上限が下がります。
m4a ビットレート（64〜320 kbps、初期値 128 kbps） 端末の AAC-LC エンコーダーが現在のサンプリングレートとチャンネル数に対応しているときに選択可能。AAC の仕組み上、元の音声よりわずかに長くなる場合があります。

保存後のデータ置き換え確認

保存 または 名前を付けて保存 で、書き出すと音が変化する形式（mp3・m4a・wav の 8 ビット）で保存した場合、「保存した内容で、編集中の音声データを置き換えますか？」という確認ダイアログが表示されます。

  • 置き換える：書き出したファイルを読み込み直した状態にします（アンドゥ履歴は空になります）。
  • 置き換えない：編集中の 16 ビット PCM データをそのまま保ちます。

wav（16 ビット）で保存した場合や、選択範囲を保存 を実行した場合はこの確認は表示されません。
